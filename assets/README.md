# Ícone do programa

Coloque aqui o ícone do LattesINK como **`icone.png`**: de preferência quadrado,
com 256×256 pixels ou mais e fundo transparente.

A partir dessa única imagem, o build gera:

- o `.ico` do Windows, com todos os tamanhos (16 a 256 px), para o `.exe`;
- o ícone da janela, no Windows e no Linux;
- o ícone do atalho no menu de aplicativos, no pacote `.deb`.

Sem o arquivo, tudo funciona, mas o programa fica sem ícone próprio. O
`lattes.ico` das versões anteriores (aqui ou na raiz do projeto) ainda é aceito
no Windows.
